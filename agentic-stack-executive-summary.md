# The Agentic Stack — Executive Summary

**Source:** https://theagenticstack.vercel.app
**Relevance:** The architectural framework underlying CMPRSSN. The `L0–L8` column in the companies and individuals CSVs points directly to the layers below.

---

## The Thesis

Agent infrastructure is being built industry-wide without shared vocabulary. The Agentic Stack is a **metaframework** — not a product — that maps every primitive required to build, deploy, govern, and evolve agents running for hours, days, or months rather than minutes.

Underlying bet: **foundation models will commoditize.** Durable advantage will come from the architecture surrounding them — identity, memory, governance, orchestration, commerce.

---

## The Nine Layers

| Layer | Name | What it is |
|-------|------|------------|
| **L0** | Substrate | GPUs, storage, networking — agent-optimized compute |
| **L1** | Engine | Foundation models, inference, context windows |
| **L2** | Workbench | Agent frameworks (LangChain territory) — commoditizing fast |
| **L3** | Cortex | Identity, memory, goals, metacognition — *most important, least solved* |
| **L4** | Switchboard | Multi-agent orchestration, delegation, workflows |
| **L5** | Proving Ground | Evaluation, sandboxing, cost attribution |
| **L6** | Shield | Security, governance, policy, audit |
| **L7** | Interface | User-facing app layer, human handoff |
| **L8** | Commons | Agent-native payments, marketplaces, commerce |

Layers relate through **stable contracts** — interfaces more durable than implementations — so each can evolve independently.

---

## Two Architectures, Same Stack

- **Cognitive Architecture** (the individual agent) — L1–L3: reasoning, identity, memory
- **Governance Architecture** (the organization of agents) — L4–L8: delegation, compliance, cost, commerce

This duality is why the framework maps cleanly onto CMPRSSN's thesis: the structural ceiling enterprises hit isn't in L1–L3 (the model or framework) — it's in L4–L8 (orchestration, governance, commerce), which is where org design lives.

---

## Five Cross-Cutting Planes

Not every concern lives in one layer. Five propagate through the whole stack:

1. **Identity Fabric** — who is acting? (auth ≠ disposition)
2. **Memory Hierarchy** — what does the agent know? (6 memory types, different timescales)
3. **Context Loom** — what enters the model's attention? (*highest-leverage discipline in the stack*)
4. **Policy Cascade** — what is permitted? (governance → infra → execution)
5. **Telemetry Mesh** — what is happening? (reasoning observability, not just infra observability)

---

## Seven Governing Principles

1. Primitives over frameworks
2. Policy is infrastructure
3. Memory is hierarchical
4. Provider abstraction
5. Scope hierarchy is real
6. Interface stability
7. Observability is required

---

## Maturity Today

- **Production-ready:** L0, L1, L2, L4, L7
- **Maturing:** L3, L5, L6
- **Early-stage:** L8, self-improving agents, organizational learning

**The biggest gap:** **L3 (Cortex)** — the highest-value unsolved infrastructure problem in the stack. No major framework yet provides cognitive routing, identity arbitration, goal maintenance, and metacognitive monitoring together.

## Why This Matters for the Telegram / CMPRSSN Work

The `L0–L8` tag on each thought leader and company is a precise signal:

- **L4–L8 + Autonomous systems + Codebook revision** → the full-stack operators rewriting org playbooks around unattended agents. Highest signal for CMPRSSN's practitioner community.
- **L2–L5 + Individual to integrated** → workforce/tooling tier (e.g., enterprise CHROs) — important but lower altitude.

The framework turns the 80-person list from "smart people tweeting about AI" into a **structured signal map** of who is operating at which altitude of the agent stack.
